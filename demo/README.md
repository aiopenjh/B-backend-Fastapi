# 시연용 서버 로그 창 (demo)

시연할 때 화면 오른쪽(좁은 화면은 아래)에 **서버 로그 창**을 붙여서 앱을 켭니다.
터미널(cmd)에 찍히는 로그를 화면에서 바로 볼 수 있습니다.

팀 프로젝트 코드(`src/`)는 고치지 않습니다. 팀 앱(`src/main.py`의 `app`)을 그대로 가져와서 바깥에 미들웨어 하나만 덧씌웁니다.

## 켜는 법

저장소 맨 위 폴더에서 실행합니다. DB(Docker)와 `.env`는 평소와 같습니다.

```bash
uv run uvicorn demo.log_panel_app:app --port 8000
```

그다음 브라우저에서 `http://127.0.0.1:8000`을 엽니다 (`/`로 들어오면 식당 둘러보기로 갑니다. 로그인은 `/ui`).

평소처럼 로그 창 없이 켜려면 `src` 폴더에서 `uv run uvicorn main:app`을 그대로 쓰면 됩니다.

## 시연 데이터 채우기 (처음 한 번)

앱을 한 번 켜서 표와 기본 시드(#47)가 들어간 뒤, 저장소 맨 위 폴더에서 차례로 실행합니다. 둘 다 여러 번 돌려도 중복이 생기지 않습니다.

```bash
uv run python src/restaurant/infrastructure/seed.py restaurants_menus_sample.csv
```

```bash
uv run python demo/make_slots.py
```

- 첫 줄: 담당 2 식당 시드 (운영자·식당·메뉴 200곳)
- 둘째 줄: 모든 식당에 내일부터 14일치 예약 시간대 (12:00 · 18:00 · 19:30, 그날 시간대가 이미 있는 식당은 건너뜀). `uv run python demo/make_slots.py 30`처럼 날 수를 바꿀 수 있습니다. 팀 코드는 고치지 않고 시간대 표에 데이터만 넣습니다.

## 보이는 것

| 줄 | 예 |
| --- | --- |
| 요청 (팀 미들웨어 로그) | `GET /ui/restaurants 200 0.05s` |
| API 오류 코드 (팀 공통 오류 처리기 로그) | `SLOT_SOLD_OUT ...` |
| 화면이 잡아서 안내로 바꾼 실패 | `화면 로그인 실패 401`, `화면 예약하기 실패 409 SLOT_SOLD_OUT`, `화면 안내 403 /ui/admin/owners` |
| 서버 오류 | 긴 Traceback 대신 마지막 한 줄 |

- 로그인 화면은 브라우저의 이메일 형식 검사를 꺼 둡니다. `@` 없는 값도 서버까지 가서 401이 로그에 찍힙니다 (시연 앱에서만).
- 최근 60줄만, 최신 줄이 맨 위에 보입니다.
- 4xx는 노란색, 5xx와 오류는 빨간색입니다.
- 화면을 새로 열 때마다 갱신됩니다 (자바스크립트 없음).
- `/ui` 화면(HTML)에만 붙습니다. API(JSON)와 `/docs`는 그대로입니다.

## 주의

로그에는 주소, 오류 위치 같은 내부 정보가 들어 있습니다. **시연·테스트용**이고, 실제 배포에는 쓰지 않습니다.
